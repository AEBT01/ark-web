◆ Features 六大能力

Speed (v8 keep-alive + cache + batch DAG) × Vision (snapshot + SoM) × Safety (isolation + audit).

👁️

Vision Snapshot 视觉快照

Atomic screenshot + Set-of-Marks coordinate anchors in one call. Multimodal models click by coordinates — no selectors. GET /snapshot?annotate=1 · binary mode saves 33%.

🔌

117 Endpoints 全量控制

Navigate, trusted mouse/keyboard, React-safe fill, screenshots & PDF, cookies, storage, console, waits, batch DAG. POST /act finishes intent in 1 RTT. 一次 HTTP 即意图。

🧊

Session Isolation 会话隔离

Server-enforced per-tab queues + ALS isolation. Parallel agents share one browser without stepping on each other. 多智能体并行不串台。

🛡️

Audit Engine 审计引擎

POST /audit scores 30+ dimensions (Vitals / a11y / SEO / security / resources) 0–100 with root-cause insights, HTML reports, JSONL trends & budgets.

⛓️

Batch Chain 批量链式

POST /batch DAG runs multi-step flows in one round-trip; chain "open …" "wait-load" "screenshot" in CLI. 长链一次往返，3–5× faster.

📱

Device Emulation 设备模拟

Real CDP emulation: devices, media queries, geo mock, network conditions, auto-dark, JS toggle, CSP bypass. POST /device /media /geo.

◆ Quickstart 三步上手

2 minutes from zero to AI-driven browser. Windows 用 start.bat，macOS/Linux 用 ./start.sh。

1 · Load the extension 安装插件

# chrome://extensions → Developer mode
# Load unpacked → extension/
# Click icon → "Enable Debug" (Chrome 136+)

2 · Start the bridge 启动服务

# Windows
start.bat
# macOS / Linux
./start.sh

3 · Drive it 操控浏览器

curl http://localhost:9333/status
curl -X POST http://localhost:9333/open \
  -d '{"url":"https://example.com"}'
curl "http://localhost:9333/snapshot?annotate=1"

◆ Security 安全说明

⚠ Localhost-only by design, no auth. 仅限本机调试： Bridge Server binds localhost:9333 / WS :9334 with no authentication — any local process can fully drive your browser. Never expose the ports, never run in untrusted environments. 请勿将端口暴露到局域网/公网。
