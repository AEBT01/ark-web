Ark Web

Control your real Chromium browser from AI. MV3 extension + local Node bridge + an AI-oriented CLI. Real CDP input, cross-frame/shadow DOM, verification-first actions, multi-browser, audit engine.

GitHub Repository · Release v5.1.2 · Agent Manual

Why it is different

Real inputCDP Input.*, not synthetic DOM events. Hover, focus, IME and default behaviours work.
State-safe refsFingerprinted ref registry; stale refs fail loudly instead of clicking the wrong element.
Cross boundariesEvery frame gets an agent; iframes and open shadow roots share one ref space.
Self-verifyingFill read-back, click effect confirmation, assertions, screenshots with numbered refs.
Multi-browserAggregate tabs, target by --browser/--conn, fan out commands in parallel.
HardenedLoopback only, token auth, extension shared secret, whitelist fail-closed, redacted audit.

Quick start

node server/bridge-server.js
# chrome://extensions -> Developer mode -> Load unpacked -> this directory
node scripts/label-browsers.js --yes
node client/browser-client.js status
node client/browser-client.js open https://example.com --tab-bg
node client/browser-client.js snapshot shot.webp --shot
node client/browser-client.js find --text "Sign in" --role button
node client/browser-client.js click --ref 12
